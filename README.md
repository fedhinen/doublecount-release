# Doublecount

Distribución de Doublecount para Android.

## Descargar

Descarga `app-release.apk` desde el [último release](https://github.com/fedhinen/doublecount-release/releases/latest).

- Versión: 1.0.0 (build 1).
- Requiere Android 7.0 (API 24) o superior.
- Arquitecturas: arm64-v8a, armeabi-v7a y x86_64.

## Instalar

Abre el APK en tu dispositivo Android y permite la instalación desde esa fuente cuando Android lo solicite.

## Verificar la descarga

Descarga `app-release.apk.sha256` junto al APK y ejecuta en macOS o Linux:

```sh
shasum -a 256 -c app-release.apk.sha256
```
